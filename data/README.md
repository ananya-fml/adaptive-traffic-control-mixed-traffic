# Data

Three tiers, never mixed:

| Folder | What | Provenance |
|---|---|---|
| `reported/` | Values **printed** in the UG report (Nov 2025) and thesis (Apr 2026) | Transcribed with document location; each row states whether it was reproduced |
| `derived/` | Tables **computed** in 2026 from the recovered exports, models, legacy code and SUMO runs | Regenerated by the scripts named below |
| `raw/` | The exports and models themselves | Private; see `raw/README.md` |

## `derived/` dictionary

| File | Produced by | Contents |
|---|---|---|
| `raw_manifest.csv` | `analysis/audit_exports.py` | SHA-256, rows, run IDs and intervals for every raw CSV, `.inpx` and `.py` |
| `run_identity.csv` | `analysis/audit_exports.py` | Content hash of every `SIMRUN` (all columns except `SIMRUN`); `distinct_output` groups identical runs |
| `distinct_simulations.csv` | `analysis/audit_exports.py` | One row per distinct simulation: network delay, stops, arrivals, latent demand, node delay (vehicle-weighted and movement mean), emissions per vehicle "as exported" |
| `comparisons.csv` | `analysis/audit_exports.py` | Adaptive vs fixed % change for the run pairs examined; `outputs_identical` flags copies |
| `interval_network_delay.csv` | `analysis/audit_exports.py` | 60 × `DELAYAVG(ALL)` per distinct simulation |
| `inpx_settings.csv` | `analysis/audit_inpx.py` | Simulation, evaluation, queue-counter, signal-head and controller settings per model and archive |
| `fixed_time_programme.csv` | `analysis/audit_inpx.py` | Raw signal-programme commands |
| `legacy_replay.csv` | `analysis/replay_legacy_controller.py` | Greens, cycle length and run end of the legacy `main()` under fixed queue inputs |
| `legacy_allocation_curve.csv` | `analysis/replay_legacy_controller.py` | `proportional_split()` output over NS queue share 0–1 |
| `sumo_runs.csv` | `sumo/run_scenarios.py` | Insertion, teleports, time loss for each SUMO package run |

Units: delays in s/veh unless stated; `*_as_exported` columns keep VISSIM's unstated units.
All derived values describe single simulations (one seed). They are descriptive, not inferential.
